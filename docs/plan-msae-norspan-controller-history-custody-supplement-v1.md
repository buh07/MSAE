# Prospective history custody supplement v1

2026-09-16. Source-free controller-plan supplement; no production authorization.

Bounded enumeration alone cannot detect an earlier public file or directory
changed during a later census yield. Retain every admitted accessible ordinary-file
and public-directory ORIGINAL FD through the complete census. Capture full original
fingerprints, exact directory names, and bounded expected file digests before yielding
objects to unchanged history consumers. Final stream-digest pass and ALL original,
named-alias and exact-name checks follow the last consumer. Do not rebase expectations.
Protected/quarantined/model-binary content is never read for these fences; retain
parent observations and lstat-only accounting. Paired phase controls may have nlink2
only at exact prescribed logical/stage names with outside expected receipt/digest.
Ordinary accessible inputs keep nlink1 semantics; no new history exemptions.

Before each retained child descriptor, monitor current-process descriptor admission
against the existing 4096 conservative client ceiling. Per-file8GiB/aggregate64GiB
observed-byte admission, object65536 and depth64 limits are operational stops, not
hard kernel quotas or history sampling. Admission failure BLOCKS full accessible
history: never silently skip, prune or exclude an object. No requirement to reach an
older maximum if a stricter FD/byte admission limit is hit. All owned descriptors
are released once on success/error/interruption/generator close; no subject removed.

This remains controlled-writer finite multi-observation, not an atomic snapshot or
exclusion of arbitrary same-UID/remote writes during/after the final observation.
Tests must reproduce both earlier-file and earlier-directory late drift before fixes,
plus iterator/descriptor fault cleanup and untouched protected lstat-only behavior.
Actual runtime/scientific histories remain inaccessible under unconditional guard.
